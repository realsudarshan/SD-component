## Usage

```tsx
import { formatDate, formatTime, formatDateTime } from "@/lib/format-date"
```

```tsx
const date = new Date()

console.log(formatDate(date)) // "September 12, 2026"
console.log(formatTime(date)) // "04:59 PM"
console.log(formatDateTime(date)) // "September 12, 2026 at 04:59 PM"
```

## API

### formatDate

Formats a date as a readable date string.

**Parameters:**
- `date` - Date object or date string

**Returns:** Formatted date string

### formatTime

Formats a date as a readable time string.

**Parameters:**
- `date` - Date object or date string

**Returns:** Formatted time string

### formatDateTime

Formats a date as a readable date and time string.

**Parameters:**
- `date` - Date object or date string

**Returns:** Formatted date and time string

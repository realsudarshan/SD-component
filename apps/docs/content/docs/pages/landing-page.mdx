## Features

- **Hero Section**: Eye-catching introduction with call-to-action buttons
- **Features Grid**: Three-column layout showcasing key features
- **Call-to-Action Section**: Final conversion section with buttons
- **Responsive Design**: Mobile-friendly layout
- **Modern Styling**: Clean, professional appearance

## Usage

This page is designed to be used as your main landing page. It includes:

1. Navigation header with logo and menu
2. Hero section with headline and CTA buttons
3. Features section with three feature cards
4. Bottom CTA section
5. Footer with copyright

Simply install the page and customize the content to match your brand and messaging.

## Customization

You can easily customize:

- **Colors**: Modify the Tailwind classes to match your brand
- **Content**: Update text, headings, and descriptions
- **Layout**: Adjust grid columns and spacing
- **Components**: Replace with your own components as needed
